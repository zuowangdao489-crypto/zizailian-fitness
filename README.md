# 自在练

免费、中文、适合手机的个人健身入门工具。直接在页面里填写资料，依据健康筛查、器材、日程与目标生成起步方案。

- 无账号、无收费 AI 接口、无广告、无分析追踪。
- 数据只保存到当前浏览器，可导出和导入 JSON 备份。
- 训练安排、21 个动作的中文步骤、30 张开源起止图示、逐组记录、组间计时、饮食搭配和趋势记录。
- 自动计划范围：18–64 岁、未报告相关健康风险的成人。不是诊疗、康复或实时动作评估工具。
- 核对过 ACSM 2026 力量训练立场声明、WHO 活动指南、ISSN 蛋白质立场声明等。完整来源在应用的“我的 → 专业依据”。

## 使用

通过 HTTPS 静态网站打开，苹果手机使用 Safari 的“分享 → 添加到主屏幕”。页面全部由原生 HTML、CSS 和 JavaScript 构成，不需要编译、服务器数据库或 API 密钥。HTTP 局域网访问需要提供页面的电脑在线；HTTPS 才启用服务工作线程缓存。

浏览器清理数据、换设备或换网址可能导致记录不可用。请定期导出备份。外部资料网站仍需要联网，锁屏或后台计时不保证提醒。

## 数据与素材

网站仓库仅包含空白工具和通用资料，不包含使用者填写的个人数据。不要将个人备份提交到仓库。

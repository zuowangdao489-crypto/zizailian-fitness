# 自在练

免费、中文、支持苹果手机和电脑的个人健身入门工具。直接在页面里填写资料，结合健康情况、器材、日程、目标和训练反馈安排起步方案。

- 无账号、无收费 AI 接口、无广告、无分析追踪。
- 数据只保存到当前浏览器，可导出和导入 JSON 备份。
- 四周入门路线、未来七天日程、当天时间调整、25 个动作的中文步骤、30 张开源起止图示、逐组记录、组间计时、饮食搭配和趋势记录。
- 筛查采用普通、适配、补充信息及需要评估等路径；年龄较大、稳定偏瘦和体重偏高不单独否决全部训练。具体方案仍取决于症状、活动能力与相关健康限制。
- 训练与营养分别判断；真正需要医学评估或不在可靠覆盖范围的情况不会自动套用普通成人处方。本工具未经临床验证，不是诊疗、康复或实时动作评估工具。
- 参考 Keep 的目标、日程、跟练与反馈流程，使用本地可审查规则实现；不调用其服务、复制其课程或宣称复现其全部 AI 能力。
- 核对过 ACSM 2026 力量训练立场声明、WHO 活动指南、ISSN 蛋白质立场声明等。完整来源在应用的“我的 → 专业依据”。

## 使用

通过同一 HTTPS 静态网站打开：苹果手机可使用 Safari 的“分享 → 添加到主屏幕”，电脑直接用浏览器打开并收藏。页面全部由原生 HTML、CSS 和 JavaScript 构成，不需要编译、服务器数据库或 API 密钥。HTTP 局域网访问需要提供页面的电脑在线；HTTPS 才启用服务工作线程缓存。

手机与电脑各自使用浏览器本地存储，不会自动同步。跨设备查看同一份资料时，在原设备导出备份并传给另一台设备，再导入；导入前确认会替换当前设备的数据并先备份。保留 v1 备份和历史记录的兼容性，新增详情在应用内补填。

浏览器清理数据、换设备或换网址可能导致记录不可用。请定期导出备份。外部资料网站仍需要联网，锁屏或后台计时不保证提醒。
